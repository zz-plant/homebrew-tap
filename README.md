# zz-plant/homebrew-tap

Homebrew formulae for [zz-plant](https://github.com/zz-plant) projects.

```sh
brew install zz-plant/tap/ambit
```

| Formula | What it does | Source |
| --- | --- | --- |
| `ambit` | Maps what you, your agents and your machines can do together, from your Claude Code, Cursor, OpenCode and other agent configs. | [zz-plant/ambit](https://github.com/zz-plant/ambit) |

Each formula installs the tagged release from npm. Report problems with a formula in the project's own repository.
